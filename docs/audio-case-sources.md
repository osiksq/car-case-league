# Case and interface audio sources

The exported MP3s are edited recordings. The frequent controls and reel ticks use short, band-limited transients. The top two reward tiers combine recorded impacts with reverberant low-frequency layers. No oscillator-generated audio is mixed into these files.

Every recording was trimmed, filtered, faded, level-adjusted, and encoded as 44.1 kHz MP3. OpenGameArt inputs are the original WAVs. Freesound inputs are the highest-quality MP3 versions linked by the source pages. Mixed assets that contain CC BY material retain its credit and license notice.
